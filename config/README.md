# 📁 مجلد الإعدادات - config

هذا المجلد يحتوي على الملفات الحساسة والإعدادات الآمنة لنظام Dashboard.

## 🔐 الملفات الموجودة:

### `admin-config.js`
الملف الرئيسي للإعدادات الحساسة:
- بيانات تسجيل الدخول المشفرة
- معلومات Google Sheets
- إعدادات Google Analytics  
- معلومات الشركة

## ⚠️ تحذيرات مهمة:

### 🚨 الأمان:
- **لا تشارك** هذا الملف مع أي شخص
- **لا ترفعه** على GitHub أو أي منصة عامة
- **احتفظ بنسخة احتياطية** في مكان آمن
- **غيّر كلمة المرور** دورياً

### 🔑 تغيير كلمة المرور:
1. اذهب لـ: https://emn178.github.io/online-tools/sha256.html
2. أدخل كلمة المرور الجديدة
3. انسخ الـ Hash الناتج
4. استبدل `passwordHash` في الملف

## 📊 إعداد Google Analytics:

### الحصول على Measurement ID:
1. ادخل على: https://analytics.google.com
2. اختر موقعك → الإدارة → معلومات التتبع
3. انسخ معرف GA4 (يبدأ بـ G-)
4. ضعه في `measurementId`

## 📋 إعداد Google Sheets:

### الحصول على Sheet ID:
من رابط Google Sheet:
```
https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit
```

انسخ الجزء بين `/d/` و `/edit` وضعه في `spreadsheetId`

## 🔧 إعدادات أخرى:

### `sessionTimeout`: مدة الجلسة بالدقائق
### `maxLoginAttempts`: عدد المحاولات المسموحة
### `blockDuration`: مدة الحظر بالدقائق
### `refresh.interval`: فترة التحديث التلقائي بالثواني
